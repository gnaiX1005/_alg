# SAT 布林滿足問題求解

- [sat.py](sat.py)

## 我的理解

SAT 就是在問：給一個布林公式，有沒有辦法填變數的真假值，讓整個公式變成真？我把它想成「走迷宮」，變數的每一種 True/False 組合是一條路，只要有一條路通到出口（公式等於真），答案就是 SAT；每條路都堵死就是 UNSAT。

因為變數只有真假兩種值，所以 n 個變數全部組合有 2^n 種，暴力法就是把這些組合全部列出來一組一組試。變數一多，組合數會爆炸，所以超過約 20 個變數就跑不動了。

## 程式原理

公式用 CNF 存成串列的串列，例如 `[1, 2]` 是一個括號，代表 x1 OR x2，負號表示取反。程式用 `itertools.product` 產生所有 True/False 組合（真值表），每一個組合依序檢查每個括號：有任一個條件為真該括號就過關，所有括號都過關，整條公式才算真。最終把通過的組合印出來，只要至少一組就印 SAT。
