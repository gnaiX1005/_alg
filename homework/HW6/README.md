# Lambda Calculus 完整解譯器

我用 gemini

## 我的理解

Lambda Calculus 是計算理論的基石，所有的計算都能用「λ抽象（定義函數）」與「應用（呼叫函數）」這兩種操作來表達。這次作業要實作一個完整的 λ-演算解譯器，核心功能包括：

1. **正規序歸約**：最左最外層優先，保證若存在正規形式一定能找到
2. **α-轉換**：自動重命名綁定變數，避免自由變數被捕捉
3. **β-歸約**：函數應用時把實參代入形參
4. **δ-展開**：把具名巨集（如 TRUE、PLUS、Y）遞迴展開成純 Lambda
5. **雙模式輸入**：支援「有名稱」寫法（易讀）與「沒名稱」純 Lambda（理論純粹）互轉
6. **Church 編碼內建庫**：SKI 組合子、布林邏輯、自然數與四則運算、比較、Pair/List、Y-Combinator 遞迴
7. **結果自動逆向識別**：把歸約結果比對內建常數（α-等價）並解碼 Church 數值
8. **互動式 REPL**：可即時輸入表達式、查環境、定義新函數、看純 Lambda 展開

程式架構分層清楚：AST（Var/Abs/App）→ Parser → 歸約引擎（step_normal）→ 識別器 → evaluate/REPL，每層職責單一，方便擴充。

## 程式原理

### 抽象語法樹 (AST)
- `Var(name)`：變數
- `Abs(param, body)`：λ 抽象，支援多參數合併顯示 `λx y. body`
- `App(func, arg)`：函數應用，左結合 `A B C` 相當於 `((A B) C)`

### 正規序單步歸約 `step_normal`
1. 遇到 **Var** 且在環境表 → δ-展開
2. 遇到 **App(Abs, arg)** → β-歸約，必要時自動 α-轉換（`substitute` 會檢查自由變數是否會被捕捉，捕捉則 `fresh_var` 產生新名稱）
3. 否則遞迴歸約 `func` 再歸約 `arg`（正規序：先動函數位置）
4. 遇到 **Abs** → 進入主體歸約（排除被遮蔽的參數名）

### 巨集展開 `expand_all_macros`
遞迴把所有自由變數若在環境表中就替換成定義體，並遞迴展開定義體內的巨集，直到變成 100% 沒有自由變數的純 Lambda 表達式。

### 結果識別 `identify_result`
1. `decode_church_numeral`：檢查是否為標準 Church 數 `λf.λx. f (f ... x)`，計算次數回傳整數
2. `alpha_equiv`：與環境中所有常數（先 `expand_all_macros`）做 α-等價比對，找出對應名稱（如 TRUE、FALSE、PAIR、Y 等）

### REPL 指令
- 直接輸入表達式 → 計算並顯示逐步歸約
- `pure <expr>` → 顯示純 Lambda 版本
- `def NAME = <expr>` → 動態加入環境
- `env` → 列出目前所有定義
- `quit`/`exit` → 離開

## 結論

完整實作了 Lambda Calculus 解譯器，8 大類經典範例全部通過：
- SKI 組合子恆等式 `S K K = I`
- 布林邏輯 `XOR TRUE FALSE = TRUE`
- 自動 α-轉換正確避免變數捕捉
- Church 算術 `MULT 2 (PLUS 1 2) = 6`、`SUB 3 1 = 2`
- 條件分支 `IF (LEQ 2 3) 4 0 = 4`
- Pair/List 資料結構 `HEAD (TAIL [1,2]) = 1`
- Y-Combinator 匿名遞迴 `Y FACT_STEP 3 = 6`

兩種模式（有名稱 / 純 Lambda）結果完全一致，證明巨集展開與歸約引擎正確。自動識別功能能精確解碼 Church 數值並辨識內建常數名稱，REPL 可即時互動測試，達到教學與實驗雙重目的。
