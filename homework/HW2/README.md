# 遞迴方程式求解

我用 opencode

## 我的理解

這題要解四條遞迴式，算出精確公式或 Big O。我理解遞迴式就像「後一步要從前一步推」：

- 第 1 條 `T(n)=T(n-1)+8`：每走一步加 8，走 n-1 步，得 `T(n)=8n-7`，線性 O(n)。
- 第 2 條 `T(n)=2T(n-1)+9`：每步把上一個值乘以 2，值會快速長大，`T(n)=10*2^(n-1)-9`，是指數 O(2^n)。
- 第 3 條 `T(n)=2T(n/2)+1`：每次分成兩半再合併，總共 O(n)，`T(n)=2n-1`。
- 第 4 條 `T(n)=T(n/2)+1`：每次都切一半，只做 log 次，`T(n)=log2(n)+1`，O(log n)。

## 程式原理

程式用迴圈直接照題目的規則一步步算實際值（T1、T2、T3、T4），另外再依我推導的公式算一次，兩邊比對是否相等。執行結果每一項都相符，代表公式推對了，例如 n=100 時 T2 遞迴值跟公式值都是相同的超大數字。這就是用程式驗證數學推導。
