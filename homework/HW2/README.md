# HW2 — 遞迴方程式求解

## 題目與解法

### 1. T(n) = T(n-1) + 8, T(1) = 1

展開：
```
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = ...
     = T(1) + 8(n-1) = 1 + 8n - 8
     = 8n - 7
```
**複雜度：O(n)**

### 2. T(n) = 2T(n-1) + 9, T(1) = 1

展開：
```
T(n) = 2T(n-1) + 9
     = 2(2T(n-2) + 9) + 9 = 4T(n-2) + 2·9 + 9
     = ...
     = 2^(n-1)·T(1) + 9(2^(n-1) - 1)
     = 2^(n-1) + 9·2^(n-1) - 9
     = 10·2^(n-1) - 9
```
**複雜度：O(2^n)**

### 3. T(n) = 2T(n/2) + 1, T(1) = 1 （n 為 2 的冪，n = 2^k）

```
T(n) = 2T(n/2) + 1
     = 2^k·T(n/2^k) + (2^k - 1)
     T(1) 時 2^k = n
     = n·1 + (n - 1)
     = 2n - 1
```
**複雜度：O(n)**（符合 Master Theorem：a=2, b=2, f(n)=1 → n^(log2 2)=n）

### 4. T(n) = T(n/2) + 1, T(1) = 1 （n 為 2 的冪，n = 2^k）

```
T(n) = T(n/2) + 1 = T(n/2^k) + k
     T(1) 時 n = 2^k → k = log2(n)
     = 1 + log2(n)
```
**複雜度：O(log n)**
