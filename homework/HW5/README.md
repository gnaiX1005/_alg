## 1. 河內塔問題（`hanoi.py`）遞迴與禁止遞迴兩種解法

### 我的理解

河內塔是「把 n 個盤子從 A 柱搬到 C 柱，一次只能搬一個，而且大盤不能壓在小盤上」。遞迴的想法很直覺：要搬 n 個，就先搬上面 n-1 個到輔助柱 B，把最大的第 n 個搬到 C，最後再把那 n-1 個從 B 搬回 C；n-1 個又用同樣的方法解決，縮到 n=0 就結束。

「禁止遞迴」版本我學到一個很漂亮的規律：最少步數固定是 2^n-1 步，而且只要**奇數步搬最小盤、偶數步搬另外兩柱中唯一能合法移動的盤子**就一定會完成。最小盤該往哪個方向繞，由 n 的奇偶決定——n 為奇數時走 A→C→B→A，n 為偶數時走 A→B→C→A。

### 程式原理

- `hanoi_recursive(n, src, dst, aux)`：三步驟遞迴，把每一步 `(盤子編號, 來源柱, 目標柱)` 記進 list。
- `hanoi_iterative(n, src, dst, aux)`：用三個 list 當柱子（index 0 是頂端），完全不呼叫自己。奇數步用 `order` 環繞移動盤子 1；偶數步在另外兩柱間比較頂端盤子，把小的疊到大的（或空柱）上。
- 主程式對 n=1,2,3,4 分別跑兩種解法，並用 `rec == it` 檢查兩者每一步是否完全一致。

### 執行結果

以 n = 3 為例（最少 7 步），兩種解法輸出完全相同：

```
===== n = 3 個盤子（最少需要 2^3-1 = 7 步）=====
[遞迴]   共 7 步：
  第  1 步: 將盤子 1 從 A 移到 C
  第  2 步: 將盤子 2 從 A 移到 B
  第  3 步: 將盤子 1 從 C 移到 B
  第  4 步: 將盤子 3 從 A 移到 C
  第  5 步: 將盤子 1 從 B 移到 A
  第  6 步: 將盤子 2 從 B 移到 C
  第  7 步: 將盤子 1 從 A 移到 C
[非遞迴] 共 7 步：（內容與上面逐行相同）
兩種解法步數相同，且每一步的盤子與柱子都一致：True
```

四個 n 的比對結果：

```
n = 1  遞迴 1 步 / 非遞迴 1 步   一致：True
n = 2  遞迴 3 步 / 非遞迴 3 步   一致：True
n = 3  遞迴 7 步 / 非遞迴 7 步   一致：True
n = 4  遞迴 15 步 / 非遞迴 15 步  一致：True
```

結論：非遞迴版本每一步都跟遞迴版本一模一樣，步數也確實是 2^n-1，證明只要掌握「奇數步搬最小盤、偶數步搬另一個」的規律，不用遞迴也能解河內塔。

## 2. 符號微分 `sym_diff(expr)`（`sym_diff.py`）

### 我的理解

符號微分就是「把公式本身當成資料，套用微分規則直接算出另一條公式」，而不是代數字。因為運算式是一層一層疊起來的（加減乘除、次方、函數），所以最自然的做法就是**遞迴**：先分別對左邊、右邊求導，再按照規則組回去。例如乘法用乘積法則 `(uv)' = u'v + uv'`、除法用商法則 `(u/v)' = (u'v - uv')/v²`、連鎖法則 `(f(u))' = f'(u)·u'`。

### 程式原理

- 運算式用 tuple 表示，例如 `x^2 + 3x + 2` 寫成 `add(pow(var('x'), const(2)), add(mul(const(3), var('x')), const(2)))`。
- `sym_diff(e)`：對每個節點套用對應微分規則，遞迴往下拆，回傳新的運算式；支援 `+ - * /`、常數次方、`sin cos exp ln`。
- `simplify(e)`：把結果化簡，例如 `0+x → x`、`1*x → x`、`x*0 → 0`、常數先合併、`x-x → 0` 等，讓輸出可讀。
- `to_str(e)`：把運算式印成正常的數學字串（含括號優先順序處理）。
- 驗證方式：用中央差分 `(f(x+h)-f(x-h))/2h` 算出數值微分，跟符號微分的結果在 x=0.5、1.5、2.0 三點比對。

### 執行結果

```
f(x)  = x ^ 2 + 3 * x + 2
f'(x) = 2 * x + 3
    x=0.5  符號微分= 4.000000  數值微分= 4.000000  相符=True
    x=1.5  符號微分= 6.000000  數值微分= 6.000000  相符=True
    x=2.0  符號微分= 7.000000  數值微分= 7.000000  相符=True
    => 微分結果正確：True

f(x)  = x ^ 3
f'(x) = 3 * x ^ 2                     （全部相符）

f(x)  = sin(x) * x
f'(x) = cos(x) * x + sin(x)           （全部相符，乘積法則）

f(x)  = exp(x) * x
f'(x) = exp(x) * x + exp(x)           （全部相符）

f(x)  = ln(x)
f'(x) = 1 / x                         （全部相符）

f(x)  = (x + 1) / (x - 1)
f'(x) = (x - 1 - (x + 1)) / (x - 1) ^ 2   （全部相符，商法則）
```

結論：六個例子（多項式、乘積、合成、對數、商）的符號微分都跟數值微分吻合，其中 `x²+3x+2 → 2x+3`、`x³ → 3x²`、`ln(x) → 1/x` 化簡後正是課本答案，證明用遞迴拆解運算式就能實作符號微分。

## 3. 自製 map / filter / reduce 與無迴圈泡沫排序（`bubble_sort.py`）

### 我的理解

函數式編程的精神是「用函數組合來處理資料」，其中最有名的三個工具就是 map（逐一轉換）、filter（篩選）、reduce（合併成一個值）。這題要求自己把它們寫出來，而且寫法不能用迴圈，所以全部改用**遞迴**：`my_reduce` 每次拿第一個元素跟累加值合併，丟給剩下的；`my_map`、`my_filter` 再站在 `my_reduce` 上實作。

至於泡沫排序，關鍵是「一趟會把最大的推到最後」。我把它拆成：一趟用 `my_reduce` 掃過相鄰元素做交換，做完最後一個就定位；然後遞迴對前面 n-1 個再做一次，直到剩一個元素。整個過程沒有用到任何 `for`/`while`。

### 程式原理

- `my_reduce(f, xs, init)`：`if not xs: return init`，否則 `f(init, xs[0])` 跟 `xs[1:]` 繼續遞迴。
- `my_map(f, xs)` = `my_reduce(lambda acc, x: acc + [f(x)], xs, [])`。
- `my_filter(pred, xs)` = `my_reduce(lambda acc, x: acc + [x] if pred(x) else acc, xs, [])`。
- `bubble_pass(xs)`：用 `my_reduce` 帶著狀態 `(done, carried)`。`carried` 是正在往後冒的最大盤子；遇到比它小的就交換（`carried` 繼續往後冒），遇到比它大的就讓 `carried` 落地。
- `bubble_sort(xs)`：遞迴 `bubble_sort(passed[:-1]) + [passed[-1]]`，把每趟最後定好的元素接在後面。
- `is_sorted(xs)`：再用 `my_reduce` 檢查相鄰每對是否遞增，驗證排序正確。

### 執行結果

```
===== 自製 map / filter / reduce 示範 =====
原始          : [1, 2, 3, 4, 5, 6]
my_map(平方)  : [1, 4, 9, 16, 25, 36]
my_filter(偶) : [2, 4, 6]
my_reduce(加) : 21

===== 泡沫排序（禁止迴圈，只用自製函數 + 遞迴）=====
原始: [5, 2, 9, 1, 5, 6]  ->  排序後: [1, 2, 5, 5, 6, 9]  正確: True
原始: [3, 3, 1, 2, 8, 0, 7]  ->  排序後: [0, 1, 2, 3, 3, 7, 8]  正確: True
原始: [10, -1, 3, 0, -5]  ->  排序後: [-5, -1, 0, 3, 10]  正確: True
原始: [1]  ->  排序後: [1]  正確: True
原始: []  ->  排序後: []  正確: True
```

結論：五組資料（含重複值、負數、單元素、空 list）排序結果都跟 Python 內建 `sorted()` 一致，且 `is_sorted` 也通過。整支程式只靠自製的 `my_map`/`my_filter`/`my_reduce` 加遞迴完成，完全沒有使用迴圈，體現了函數式編程「用函數組合取代迴圈」的核心想法。
