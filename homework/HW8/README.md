# 第7週習題：優化算法 — 旅行推銷員問題（TSP）

我用 opencode

本次作業分別用五種方法來解決旅行推銷員問題（Traveling Salesman Problem, TSP）：改良法（2-opt）、爬山演算法、模擬退火法、梯度下降法、貪婪演算法。

## 1. 問題定義

給定 $n$ 個城市與城市之間的距離，找出一條**每個城市恰好走訪一次，最後回到起點**的最短路徑（哈密頓迴路）。

路徑長度定義為：
$$
L(\pi)=\sum_{i=0}^{n-1} d(\pi_i, \pi_{(i+1)\bmod n})
$$

本作業以 $n=20$ 的隨機城市（固定亂數種子 42）為測試資料。

## 2. 五種方法說明

### (1) 貪婪演算法（最近鄰居法）－`tsp_greedy.py`
從起點開始，每次選擇「距離最近且尚未造訪」的城市加入路徑，直到所有城市都走過後再回到起點。這是建構式啟發法，只考慮當前最短一步，缺乏全域考量。

### (2) 改良法（2-opt）－`tsp_twoopt.py`
以貪婪演算法產生的初始解為起點。每次從路徑中選取兩條不相鄰的邊 $(a,b),(c,d)$，將路徑中 $b$ 到 $c$ 之間的順序反轉，形成新的路徑 $(a,c,...,b,d)$。若總長度減少（$\Delta = d(a,c)+d(b,d)-d(a,b)-d(c,d) < 0$）則接受此改動，重複直到無法再改善（達到 2-opt 局部最佳解）。

### (3) 爬山演算法（Hill Climbing）－`tsp_hillclimb.py`
隨機產生一條初始路徑，每次隨機交換兩個城市的位置產生鄰居解。若鄰居解較短就接受，否則就還原回原本的路徑。只接受「往下走」（變好的解），因此容易陷入局部最佳解。

### (4) 模擬退火法（Simulated Annealing）－`tsp_sa.py`
借鑑金屬退火的概念：初始溫度 $T_0$ 較高時，允許以機率 $P=\exp(-\Delta/T)$ 接受較差的解（$\Delta>0$），有助於跳出局部最佳。隨著每次降溫（$T \leftarrow \alpha T$），接受差解的機率逐漸降低，最後收斂到較好的解。本實作使用 2-opt 的反轉鄰域，並記錄搜尋過程中找到的最佳解。

### (5) 梯度下降法（Gradient Descent）－`tsp_gd.py`
由於 TSP 是離散問題，無法直接求梯度。因此先做**連續鬆弛**：用機率矩陣 $P_{k,i}$ 表示「第 $k$ 步造訪城市 $i$」的機率，並對參數 $W$ 做 row-softmax 取得 $P$。定義期望路徑長度 $L(P)=\sum_k P_k^T D P_{k+1}$ 以及懲罰項 $R(P)=\lambda \sum_i (\sum_k P_{k,i}-1)^2$（迫使每個城市恰好被訪問一次），以梯度下降更新 $W$ 最小化 $L+R$。優化結束後以貪婪方式從 $P$ 解碼出一個合法的城市排列。
