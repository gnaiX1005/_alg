# 數學、語言、機器與程式 — 閱讀筆記

我用 claude 幫我整理重點，再自己看過一遍。

整本書在回答一個問題：**能不能寫一個程式，自動證明所有數學定理？**
從 1900 到 1972 年，幾個人從不同角度給了答案。

---

## 第 1 章　希爾伯特：問題的起點

- 1900 年提出 23 個問題，第 2 題「算術公理的相容性」影響最大
- 想學《幾何原本》那樣，從少數公理出發，把推論**完全機械化**
- `inference.py`：前向推論，一直套規則直到推不出新東西（例：會飛＋生蛋＋長腿 → 鳥 → 鴕鳥）
- **希爾伯特綱領**：形式化、完備性、一致性、保守性、確定性
- 推論引擎只能推單一變數，推不出邏輯法則本身，要推法則就得引入公理

## 第 2 章　哥德爾：夢想破滅

- 羅素悖論（理髮師悖論）讓樸素集合論出問題，後來用 ZFC 修好
- **完備性定理（1929）**：一階邏輯裡的恆真式都證得出來
- **不完備性定理（1931）**：只要包含算術又一致，就一定有證不了也否證不了的命題
- 兩個不衝突，差別在加了算術後可以編碼「可證明」，做出「這句話無法被證明」這種自我指涉的句子

## 第 3 章　丘奇：只靠函數就能算一切

- λ-Calculus 只有抽象 `λx.M` 跟應用 `M N`，核心是 β-reduction
- 沒有 bool、沒有 int，全部用函數做出來：
  - TRUE 選左邊、FALSE 選右邊
  - Church numerals：數字 n = 把 f 套用 n 次
  - Y-Combinator 讓匿名函數可以遞迴（寫出階乘、費氏數列）
  - CONS / CAR / CDR 做串列
- 1936 年證明：沒辦法判斷兩個函數的行為是否相同

## 第 4 章　圖靈：計算的機器

- **FSM**：沒有記憶，只能做簡單判斷（例：0 的個數是不是偶數）
- **圖靈機**：FSM＋可讀寫的磁帶，可以辨識 aⁿbⁿcⁿ
- **停止問題**（重點）：假設有 `isHalt`，就能寫一個故意唱反調的 `U`，`U(U)` 怎麼答都矛盾，所以 `isHalt` 不存在

```python
def U(f):
    if isHalt(f, f):
        while True: pass   # 說會停就不停
    else:
        return             # 說不停就馬上停
```

- 設逾時也沒用，分不出是跑很久還是永遠不停
- 現代電腦 ≈ 記憶體有限的圖靈機，圖靈機解不了的它也解不了

## 第 5 章　喬姆斯基：語言的階層

- 生成語法：用規則一直代換產生句子（`grammar.py`），跟程式語言的 BNF 是同一個概念

| 類型 | 語言 | 對應機器 | 例子 |
|---|---|---|---|
| Type 0 | 遞迴可枚舉 | 圖靈機 | — |
| Type 1 | 上下文相關 | 線性有界自動機 | aⁿbⁿcⁿ |
| Type 2 | 上下文無關 | 下推自動機 | aⁿbⁿ |
| Type 3 | 正規 | 有限狀態機 | aⁿbᵐ |

- 數字越小，語法越自由，需要的機器越強
- **丘奇–圖靈論題**：能用演算法算的都能用圖靈機算，所以第 3、4 章其實是同一件事

## 第 6 章　庫克：可解，但太慢

- 前面問「能不能算」，這章問「算多快」
- **P**：多項式時間解得出來；**NP**：給一個解，多項式時間驗證得了
- **歸約**：把 A 問題轉成 B 問題來解（例：八皇后轉成整數規劃，丟給 `mip`）
- **SAT**：布林式能不能被滿足，暴力法是 2ⁿ
- **Cook–Levin**：SAT 是 NP-Complete，SAT 能快速解的話所有 NP 都能
- P = NP 到現在還沒人解出來

## 全書主線

```
希爾伯特：能不能機械化證明所有定理？
   ├─ 哥德爾(1931)：不行，有真但不可證的命題（邏輯）
   ├─ 丘奇(1936)  ：不行，函數等價不可判定（函數）
   └─ 圖靈(1936)  ：不行，停止問題不可判定（機器）
         │
   喬姆斯基(1957)：語法階層 ↔ 機器階層
         │
   庫克(1972)    ：就算可解，也可能慢到不能用
```

三個「不行」用的都是同一招：**自我指涉製造矛盾**。
