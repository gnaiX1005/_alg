# power2n 四種寫法的效率比較

我用 opencode

## 我的理解

這題要我用四種方式算 2 的 n 次方，然後比較誰快誰慢。我自己想了一下，四種寫法差別在「怎麼拆」：

- 方法 1 直接 `2**n`，一次就算完，最快。
- 方法 2a 寫成 `power2n(n-1) + power2n(n-1)`，每呼叫一次就分裂成兩支，總共會分裂 2^n 支，n=100 根本算不完。
- 方法 2b 寫成 `2 * power2n(n-1)`，只遞迴一次，n 次就做完。
- 方法 3 是遞迴加上查表，把算過的值記起來，就不會重複算。

## 程式原理

主程式對每個函數記錄執行時間，n=100。方法 2a 我加了 5 秒的時限，超過就判定「跑不出來」，不然程式會卡住永遠停不下來。執行結果：方法 1、2b、3 都是瞬間完成，只有 2a 會超時，這就是 O(2^n) 指數爆炸的可怕。

## 執行結果

```
測試 n = 100（預期結果 = 2**100）

方法1 (2**n)         結果=1267650600228229401496703205376 正確=True 耗時=0.000001s
方法2a (+遞迴)         n=100 超出 5 秒，跑不出來（時間複雜度太高）
方法2b (*遞迴)         結果=1267650600228229401496703205376 正確=True 耗時=0.000013s
方法3 (查表)           結果=1267650600228229401496703205376 正確=True 耗時=0.000043s

結論：
  方法1: 直接 2**n，O(1)，瞬間完成
  方法2a: 每次分裂成兩個呼叫，O(2^n)，n=100 根本跑不完
  方法2b: 每次只遞迴一次，O(n)，很快
  方法3: 查表記錄算過的結果，O(n)，一樣快
```
