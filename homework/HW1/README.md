# HW1 — power2n 效率比較

## 說明

計算 2^n 的四種寫法，測試 n = 100 的執行效率。

| 方法 | 寫法 | 時間複雜度 |
|------|------|-----------|
| 方法 1 | `2 ** n` | O(1) |
| 方法 2a | `power2n(n-1) + power2n(n-1)` | O(2^n) |
| 方法 2b | `2 * power2n(n-1)` | O(n) |
| 方法 3 | 遞迴 + 查表 (memoization) | O(n) |

## 執行結果（n = 100）

```
測試 n = 100（預期結果 = 2**100）

方法1 (2**n)         結果=1267650600228229401496703205376 正確=True 耗時=0.000001s
方法2a (+遞迴)         n=100 超出 5 秒，跑不出來（時間複雜度太高）
方法2b (*遞迴)         結果=1267650600228229401496703205376 正確=True 耗時=0.000013s
方法3 (查表)           結果=1267650600228229401496703205376 正確=True 耗時=0.000043s
```

## 結論

- **方法 1**：直接指數運算，瞬間完成。
- **方法 2a**：每次呼叫會分裂成兩支，總呼叫數為 O(2^n)，n = 100 時呼叫數高達 2^100 次，理論上跑不完（幾乎出不來）。
- **方法 2b**：每次只遞迴一次，O(n)，n = 100 很快。
- **方法 3**：把算過的結果記在查表內，避免重複計算，即使寫成 `power2n(n-1)+power2n(n-1)` 也只需 O(n) 次，又快又安全。

python power2n.py
