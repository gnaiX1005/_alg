## 1. 單變數微分與積分 — `Q1.py`

### 我的理解

電腦沒辦法真的取極限，所以微分只能用「很小但不是 0 的 $h$」來近似導數定義；積分則是把區間切成很多小塊，把每一塊的面積加起來。不同方法的差別在於「怎麼取點」，取得越聰明，誤差下降得越快。

### 程式原理

**微分**

- 前向差分：$f'(x) \approx \dfrac{f(x+h)-f(x)}{h}$，誤差 $O(h)$。
- 中央差分：$f'(x) \approx \dfrac{f(x+h)-f(x-h)}{2h}$，左右對稱讓一次項誤差互相抵消，誤差 $O(h^2)$。

**積分**（把 $[a,b]$ 切成 $n$ 等分，$h=(b-a)/n$）

- 黎曼和（中點法）：每個小區間取中點的函數值當高度，$\sum f(a+(i+0.5)h)\cdot h$。
- 梯形法：把每個小區間的曲線當成直線，用梯形面積相加，誤差 $O(h^2)$。
- Simpson 法：每兩個小區間用一條拋物線去貼，權重是 $1,4,2,4,\dots,4,1$，誤差 $O(h^4)$，$n$ 必須是偶數（程式會自動補成偶數）。

### 執行結果

```
=== 微分 ===
d/dx sin(x) at x=1   前向差分 = 0.5403018851
                     中央差分 = 0.5403023059
                     理論值   = 0.5403023059
d/dx x^3 at x=2      中央差分 = 12.0000000002   (理論值 12)

=== 積分 ===
∫_0^π sin(x) dx  黎曼和 = 2.0000000082
                 梯形法 = 1.9999999836
                 Simpson = 2.0000000000
                 理論值 = 2
∫_0^1 x^2 dx     黎曼和 = 0.3333333325   (理論值 0.3333333333)
```

結論：中央差分比前向差分多準了好幾位數；積分在同樣 $n=10000$ 下，Simpson 法直接準到小數點後 10 位。也可以看到中點法的誤差（+8.2e-9）大約是梯形法（−1.6e-8）的一半而且方向相反，這跟理論推導的結果一致。

## 2. 蒙地卡羅法計算單變數積分 — `Q2.py`

### 我的理解

蒙地卡羅法不是規律地切格子，而是「隨機丟點，用統計平均來估計」。積分其實就是「函數平均高度 × 區間寬度」，所以只要隨機抽夠多點算平均，就能估計積分值。

### 程式原理

- **平均值法** `mc_integral()`：$x_i \sim \text{Uniform}(a,b)$，
  $$\int_a^b f(x)\,dx \approx (b-a)\cdot\frac{1}{N}\sum_{i=1}^{N} f(x_i)$$
- **投點法（hit-or-miss）** `mc_integral_hit()`：在 $[a,b]\times[0,y_{max}]$ 的矩形內隨機投點，落在曲線下方的比例 × 矩形面積就是積分值（限 $0 \le f(x) \le y_{max}$）。
- 固定亂數種子 42，讓每次執行結果一樣。

### 執行結果

```
∫_0^π sin(x) dx，理論值 = 2
  N =     100  平均值法 = 1.958626   投點法 = 2.010619
  N =    1000  平均值法 = 2.041476   投點法 = 2.045177
  N =   10000  平均值法 = 2.005874   投點法 = 1.982345
  N =  100000  平均值法 = 1.996722   投點法 = 1.998273
  N = 1000000  平均值法 = 2.001164   投點法 = 2.000026

∫_0^1 x^2 dx，理論值 = 0.333333
  N = 1000000  平均值法 = 0.333169

∫_0^1 4/(1+x^2) dx，理論值 = π = 3.141592653589793
  N = 1000000  平均值法 = 3.140892
```

結論：隨著 $N$ 變大，估計值會往理論值靠近，誤差大約跟 $1/\sqrt{N}$ 成正比（$N$ 變 100 倍，誤差約變成 1/10）。在一維的情況下，蒙地卡羅法用 100 萬個點只準到小數點後 2～3 位，遠不如第 1 題的 Simpson 法，所以**低維積分用格點法比較划算**。

## 3. n 變數微分（梯度）與積分（超體積） — `Q3.py`

### 我的理解

多變數函數的「微分」就是梯度：對每一個變數分別做偏微分，其他變數固定不動。積分則是把第 1 題的黎曼和推廣到 n 維：每一維都切 $m$ 等分，變成 $m^n$ 個小超立方體，取每個小格子的中點值 × 小格子體積再加總。

### 程式原理

- `partial(f, x, i)`：只對第 $i$ 個變數加減 $h$，用中央差分算偏微分。
- `gradient(f, x)`：對每個變數呼叫 `partial()`，組成 $\nabla f = [\partial f/\partial x_0, \dots, \partial f/\partial x_{n-1}]$。
- `integral_nd(f, low, high, m)`：用 `itertools.product(range(m), repeat=n)` 產生所有格子索引，每個格子取中點算 $f$，乘上小格子體積 $dV=\prod h_i$ 後加總。

### 執行結果

```
=== 梯度 ===
f = x²+y²+z², ∇f(1,2,3) = [2.0, 4.0, 6.0]   理論值 [2, 4, 6]
f = x²y+sin(y), ∇f(2,0) = [0.0, 5.0]   理論值 [0, 5]

=== n 維積分（超體積） ===
∫∫(x+y) over [0,1]²            = 1.000000   理論值 1
∫∫∫(x²+y²+z²) over [0,1]³      = 0.999900   理論值 1
三維單位球體積                  = 4.191872   理論值 4π/3 = 4.188790
```

結論：梯度完全符合理論值。積分方面，平滑函數（$x+y$、$x^2+y^2+z^2$）都很準；但單位球的「在球內 = 1，否則 = 0」是不連續函數，球面邊界附近的格子會被整格算進或整格捨棄，所以誤差明顯比較大。另外三維切 100 等分就要算 $100^3 = 100$ 萬個點，可以感受到維度一高，計算量會爆炸性成長。

## 4. 蒙地卡羅法計算 n 變數積分 — `Q4.py`

### 我的理解

把第 2 題的平均值法直接推廣到 n 維：在超矩形 $\Omega$ 裡均勻隨機取點，

$$
\int_\Omega f(\mathbf{x})\,d\mathbf{x} \approx \text{Vol}(\Omega)\cdot\frac{1}{N}\sum_{i=1}^{N} f(\mathbf{x}_i)
$$

最大的好處是誤差約為 $O(1/\sqrt{N})$，**跟維度 $n$ 無關**，所以高維時比格點法好用很多。

### 程式原理

- `mc_integral_nd(f, low, high, N)`：每次在每一維各抽一個 `random.uniform(low[i], high[i])` 組成一個點，累加 $f$ 後乘上超矩形體積再除以 $N$。
- 測試函數用「點在單位球內 = 1」，在 $[-1,1]^n$ 中投點，命中比例 × $2^n$ 就是 n 維球體積。
- `ball_volume_exact(n)`：用公式 $V_n = \dfrac{\pi^{n/2}}{\Gamma(n/2+1)}$ 算理論值來對照。

### 執行結果

```
=== n 維單位球體積（投點計算比例） ===
  n =  2   蒙地卡羅 = 3.13834   理論值 = 3.14159
  n =  3   蒙地卡羅 = 4.20804   理論值 = 4.18879
  n =  4   蒙地卡羅 = 4.92752   理論值 = 4.93480
  n =  5   蒙地卡羅 = 5.23968   理論值 = 5.26379
  n =  6   蒙地卡羅 = 5.17760   理論值 = 5.16771
  n =  8   蒙地卡羅 = 4.07552   理論值 = 4.05871
  n = 10   蒙地卡羅 = 2.37056   理論值 = 2.55016

=== 其他函數 ===
  ∫ Σx_i² over [0,1]^10   = 3.32930   理論值 3.33333
  ∫ e^-(x²+y²) over [-3,3]² = 3.14374   理論值 ≈ π = 3.14159
```

結論：2～8 維的球體積都很接近理論值，而且 10 維的 $\sum x_i^2$ 積分也只差 0.004，同樣的計算量如果用格點法根本切不了幾刀。比較特別的是 10 維球誤差較大（2.37 vs 2.55），原因是 10 維單位球只占 $[-1,1]^{10}$ 立方體約 0.25% 的體積，20 萬個點裡只有大約 500 個點落在球內，命中數太少，相對誤差就變大。也可以觀察到 n 維單位球體積在 $n=5$ 左右最大，之後反而越來越小。

## 5. 用黎曼積分寫 `integral(f, low, high)` — `Q5.py`

### 我的理解

題目要求寫一個通用的 n 變數積分函數，其中 $n$ = `len(low)` = `len(high)`，並測試 $f(\mathbf{x}) = x_1^2 + \cdots + x_n^2$ 在 $[0,1]^n$ 上的積分，理論值是

$$
\int_{[0,1]^n} \sum_{i=1}^{n} x_i^2\, d\mathbf{x} = n\cdot\int_0^1 x^2\,dx = \frac{n}{3}
$$

### 程式原理

- 每一維切 $m$ 等分，總共要算 $m^n$ 個點。為了讓不同維度的計算量差不多，設定「最多算 100 萬個點」（`budget = 10**6`），自動取 $m = \lfloor 10^6{}^{1/n} \rfloor$，至少 1。
- 用**遞迴** `rec(d)` 實作 n 層迴圈：固定第 $d$ 維取中點值後，再遞迴處理第 $d+1$ 維；$d = n$ 時才真正呼叫 $f$。這樣不管幾維都能用同一個函數處理。
- 中點法對 $x^2$ 每一維的誤差是 $\dfrac{1}{12m^2}$，n 維總誤差為 $\dfrac{n}{12m^2}$。

### 執行結果

```
f(x) = x1² + ... + xn²，low = 0，high = 1，理論值 = n/3

n =   1  每維切 1000000 等分 (共 1,000,000 個點)  黎曼積分 = 0.33333333   理論值 = 0.33333333   誤差 = 8.37e-14
n =   2  每維切    1000 等分 (共 1,000,000 個點)  黎曼積分 = 0.66666650   理論值 = 0.66666667   誤差 = 1.67e-07
n =   5  每維切      15 等分 (共 759,375 個點)  黎曼積分 = 1.66481481   理論值 = 1.66666667   誤差 = 1.85e-03
n = 100  每維切       1 等分 (共 1 個點)  黎曼積分 = 25.00000000   理論值 = 33.33333333   誤差 = 8.33e+00
```

結論：實測誤差和公式 $n/(12m^2)$ 完全吻合（例如 5 維：$5/(12\times15^2)=1.85\times10^{-3}$）。1、2、5 維都能切得夠細所以很準；但 100 維就算每維只切 2 等分也要 $2^{100}\approx1.27\times10^{30}$ 個點，根本算不完，這就是**維度災難（curse of dimensionality）**。在 100 萬個點的預算下每維只能切 1 等分，結果是 $100\times0.25=25$，誤差高達 8.33。

## 6. 改用蒙地卡羅法做 n 變數積分 — `Q6.py`

### 我的理解

題目和第 5 題完全相同，只是把積分方法換成蒙地卡羅，用來對照兩種方法在高維時的差異。

### 程式原理

- `integral(f, low, high, N)`：在 $[0,1]^n$ 中隨機取 $N=100{,}000$ 個點，算 $f$ 的平均再乘上體積（這裡是 1）。
- 誤差估計：每一維 $x^2$ 的變異數為 $\dfrac{1}{5}-\dfrac{1}{9}=\dfrac{4}{45}$，所以 n 維 $f$ 的標準差 $\sigma=\sqrt{4n/45}$，估計誤差約 $\sigma/\sqrt{N}$。$n=100$ 時約 0.0094（相對誤差約 0.03%）。

### 執行結果

```
f(x) = x1² + ... + xn²，low = 0，high = 1，理論值 = n/3，取樣 N = 100,000

n =   1  蒙地卡羅 = 0.333687   理論值 = 0.333333   誤差 = 3.53e-04   相對誤差 = 0.106%
n =   2  蒙地卡羅 = 0.667445   理論值 = 0.666667   誤差 = 7.79e-04   相對誤差 = 0.117%
n =   5  蒙地卡羅 = 1.666118   理論值 = 1.666667   誤差 = 5.48e-04   相對誤差 = 0.033%
n = 100  蒙地卡羅 = 33.313668   理論值 = 33.333333   誤差 = 1.97e-02   相對誤差 = 0.059%
```

結論：蒙地卡羅在 1～100 維的相對誤差都維持在 0.1% 左右，100 維的結果是 33.31，跟理論值 33.33 非常接近；而第 5 題的黎曼積分在 100 維只能得到 25。反過來看，在 1、2 維時黎曼積分的誤差（1e-14、1e-7）遠小於蒙地卡羅（1e-4），所以兩種方法各有適合的場合。

## 8. 總結

| 方法 | 誤差量級 | 計算量 | 適合 |
| --- | --- | --- | --- |
| 前向差分 | $O(h)$ | 2 次函數呼叫 | 簡單但不夠準 |
| 中央差分 | $O(h^2)$ | 2 次函數呼叫 | 同樣成本更準，實務首選 |
| 黎曼和／梯形法 | $O(h^2)$ | $m^n$ 個點 | 低維、平滑函數 |
| Simpson 法 | $O(h^4)$ | $m$ 個點（一維） | 一維平滑函數，最準 |
| 蒙地卡羅 | $O(1/\sqrt{N})$，與維度無關 | $N$ 個點 | 高維積分、不規則區域 |

這週讓我體會到：低維時「規律切格子」的方法收斂得很快，Simpson 法一維就能準到 10 位數；但格點數是 $m^n$，維度一高就完全算不動。蒙地卡羅法雖然收斂慢（要準 10 倍得多算 100 倍的點），但它的誤差跟維度無關，所以在 100 維這種格點法完全沒辦法處理的情況下，反而成為唯一可行的方法。
